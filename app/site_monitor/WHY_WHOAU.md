# 왜 WHO.A.U 하나만 직접 수집하는가 (A 역할 결정 기록)

작성일: 2026-11-23 / 담당: A (사이트 수집 & 변화 감지)

## 1. 결론

- 4개 대상 브랜드(스파오·에잇세컨즈·무신사 스탠다드·유니클로)의 공식몰은 **예의 바른 직접 수집이 불가능**하거나 **수집이 막혀 있었다.**
- 네이버 쇼핑 API(대안)도 **지금 우리 계정으로는 쓸 수 없다.**
- 그래서 학습용으로 **robots.txt가 허용하고 실제로 응답하는 WHO.A.U(후아유, 카페24)** 한 곳을 직접 수집 대상으로 삼았다.
- 수집 규칙: 하루 1회, 요청 간격 5초 이상, 솔직한 User-Agent, robots.txt 준수, 403/429가 나오면 중단. 정렬·필터·검색 URL은 쓰지 않는다.

## 2. 네이버 API가 안 되는 사유

### 2-1. https://www.ncloud.com/ (네이버 클라우드 플랫폼, NCP)

| 확인 내용 | 결과 |
|---|---|
| 가지고 있던 키 | NCP 인증 정보(`X-NCP-APIGW-API-KEY-ID` / `X-NCP-APIGW-API-KEY`, 약 10자 + 40자) |
| NCP에서 신청 가능한 API (API 관리 화면) | 뉴스, 검색어트렌드, 쇼핑인사이트 등 |
| **쇼핑 검색 API** | **목록에 없음** (신청 체크박스에도 없음) |

- 쇼핑인사이트는 "분야별 클릭 추이" 통계 API라서, 우리가 필요한 **상품 단위 신상품·가격 정보가 나오지 않는다.**
- 쇼핑 검색 API(`openapi.naver.com/v1/search/shop.json`)는 NCP가 아니라 developers.naver.com 쪽 서비스다. NCP 키로 호출하면 401이 난다(실제로 확인함).

### 2-2. https://developers.naver.com/ (네이버 개발자센터)

| 확인 내용 | 결과 |
|---|---|
| 애플리케이션 등록 시 "사용 API" 목록 | **"검색"이 없음** |
| 웹 검색 결과 | 쇼핑 검색 API가 2026-07-31에 종료되었다는 내용이 있음 (공식 공지로는 아직 확인하지 못함) |

- "검색"이 목록에 없으면 쇼핑 검색 API의 Client ID/Secret을 발급받을 방법이 없다.
- 따라서 `naver_shopping.py` 수집기는 코드는 있으나 **키를 구할 수 없어 사용할 수 없는 상태**다. (공식 종료 여부는 개발자센터 공지에서 한 번 더 확인 필요)

## 3. 직접 수집 가능 여부 확인 결과 (의류 사이트)

기준: ① robots.txt가 상품 목록 경로를 허용 ② 서버 렌더링 등으로 단순 요청으로 응답 ③ 실제로 응답(차단 없음).

| 사이트 | robots.txt | 실제 응답 | 판정 |
|---|---|---|---|
| 스파오 (spao.com) | 봇 차단 | - | 수집 안 함 |
| 에잇세컨즈 (ssfshop.com) | 봇 차단 | - | 수집 안 함 |
| 무신사 스탠다드 (musinsa.com) | 봇 차단 | - | 수집 안 함 |
| 유니클로 (uniqlo.com/kr) | 허용 | **403/타임아웃** (연결 수준 차단) | 수집 안 함. 차단을 우회하지 않는다 |
| **WHO.A.U (whoau.com)** | **`/` 허용** (관리·주문·로그인·검색·정렬·필터 경로만 금지) | **정상 응답, 상품 HTML에 서버 렌더링** | **수집 대상으로 선정** |
| NB (nbkorea.com), 29CM | 허용으로 보임 | 미검증 | 2차 후보 |

- 유니클로: robots.txt는 허용이지만 접속이 반복해서 타임아웃/차단되었다. 봇 차단을 우회하는 것은 "예의 바른 수집"이 아니므로 시도하지 않았다.
- WHO.A.U: 카페24 쇼핑몰이라 `/product/list.html?cate_no=101` 한 요청으로 상품명·가격·이미지·상품 번호가 모두 나온다. JS 렌더링이 필요 없어 서버 부담이 가장 작다.

## 4. WHO.A.U 수집의 한계 (알고 쓸 것)

- 목록에는 **현재 판매가만** 보인다. 정가(취소선)는 사용하지 않으므로 인하는 "가격 변동"으로 감지한다.
- 품절 표시(`sold_out` 셀렉터)는 카페24 표준 아이콘을 가정한 값이며, 품절 상품이 있는 페이지로는 아직 검증하지 못했다.
- 현재는 카테고리 1개(`cate_no=101`)만 수집한다. 늘리면 요청 수가 늘어나므로 5초 간격·하루 1회 원칙을 함께 고려한다.
- 4개 브랜드 비교 대시보드는 **WHO.A.U 1개 브랜드의 데이터만 실데이터**이고, 나머지 4개는 비어 있다. 팀과 범위 조정이 필요하다.
